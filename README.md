
# OpenGLSimulation

An ongoing project focused on learning and exploring **C++ and OpenGL** for graphics programming and real-time rendering.

The goal is to gain hands-on experience with rendering techniques, graphics programming, and the fundamentals of visual simulations.

**Project status:** Work in progress

**Technologies:** C++, OpenGL, CMake

# Building and Running
Prerequisites:
- A C++ compiler
- CMake
- OpenGL-compatible graphics drivers




### 1. Clone the repository
```bash
git clone https://github.com/Aftertower8/OpenGLSimulation.git
cd OpenGLSimulation
```

### 2. Configure the project
```bash
cmake -S . -B build
```

### 3. Build the project
```bash
cmake --build build
```

### 4. Run the application

Run the generated executable from the `build` directory. The exact path depends on your operating system and build configuration.

**Note:** This project is still under development, so additional dependencies or setup steps may be required.
